# Log-ON Électriciens

Prototype web de l'app Log-ON : voir les électriciens disponibles près de chez vous et les appeler directement.

Site : https://inestanitxr.github.io/logon-electriciens/

- `docs/index.html` — l'app complète (une seule page, sans dépendances)
- `docs/manifest.webmanifest` + icônes — installation sur l'écran d'accueil
- Les profils affichés sont des profils de démonstration ; un profil créé dans « Espace pro » reste sur l'appareil.
